## MXU（介面）

::: collapse

- 什麼是 MXU？

    [MXU](https://github.com/MistEO/MXU)（MaaFramework Next UI）是基於 [MaaFramework PI V2](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.3-ProjectInterfaceV2%E5%8D%8F%E8%AE%AE.md) 協議的通用 GUI 用戶端，為本專案提供開箱即用的圖形介面。

- 為什麼選擇 MXU？

    本專案早期使用 [MFAAvalonia](https://github.com/MaaXYZ/MFAAvalonia)，這也是 [MaaFramework 專案範本](https://github.com/MaaXYZ/MaaPracticeBoilerplate)內建的 GUI。但在使用過程中，我們發現其設定方式、互動邏輯與上手難度不太符合需求。參考 [M9A](https://github.com/MAA1999/M9A)、[MAAEnd](https://github.com/MaaEnd/MaaEnd) 等專案後，開發者討論決定改用 MXU。

    對我們而言，MXU 具有設定簡單、介面互動方便、日誌管理優秀、無需 .NET 執行環境等優點。雖然仍有少量不足，但它是目前主流 MaaFramework GUI 中最適合本專案的選擇。當然，如果你偏好其他 GUI，也可以自行管理。
:::

### 設定／分頁

::: collapse

- 什麼是設定／分頁？

    MXU 會以分頁形式展示 MaaFramework 設定，方便使用者為不同用途選擇合適的設定。

- 設定包含哪些範圍？

    MXU 描述為「各設定的任務和裝置設定互相獨立」。

    實際上，設定之間的任務（任務列表、任務詳細設定、任務啟用狀態、任務展開狀態等）相互獨立；定時功能相互獨立；連線設定（控制器、連線視窗、即時截圖顯示狀態等）相互獨立。設定頁中的內容則由各設定共用。

- 關於預設設定

    我們將部分常用設定整合為幾份預設，首次啟動軟體時會自動套用。若不需要，也可以關閉分頁來刪除該設定。

    如果誤刪了預設設定，想要重新加入，只需在新增設定時選擇對應預設即可。

- 關於定時執行設定

    在設定右下角，可以透過定時功能讓某個設定定時執行。此功能在各設定之間相互獨立。
:::

### 任務

::: collapse

- 什麼是任務？

    MaaNTE 中的各項自動化功能會作為獨立「任務」存在，你可以依需求自由啟用或停用。每個任務對應遊戲中的一個具體操作或玩法，例如[領取獎勵](../introduction/Daily/ClaimRewards.md)、[自動釣魚](../introduction/HethereauHobbies/Fish.md)等。

    你可以在任務列表中勾選需要執行的任務，MaaNTE 會按列表順序依次執行。

- 任務如何分類？

    任務主要按功能類型分為以下幾類：

    - **日常任務**：領取活躍度獎勵、環期賞令獎勵、家具獎勵、一咖舍收益等每日重複操作。
    - **實時輔助**：自動拾取、跳過劇情、自動傳送、音訊閃避、快速拾取等遊玩時執行的輔助功能。
    - **都市大亨**：一咖舍經營、房產家具等都市大亨玩法相關功能。
    - **都市閒趣**：自動做咖啡、釣魚、粉爪大劫案、俄羅斯方塊、超強音等都市閒趣小遊戲自動化。
    - **其他功能**：自動彈琴、撫摸、噴泉打卡等娛樂性功能與暫時尚未完善的功能。
    - **資料收集**：用於開發與最佳化功能的資料採集，預設不開啟。

    可前往[功能介紹](../introduction/README.md)查看各類任務的詳細說明。

- 什麼是任務列表？

    任務列表是 MXU 分頁中偏左側的一大片區域，用來展示該設定中加入的各個任務。你可以在此對任務進行詳細設定。

- 任務執行順序是怎樣的？

    任務會**按任務列表由上到下依序執行**，並跳過未勾選的任務。你可以拖曳任務標題左側的六個點來調整順序。

- 為什麼不支援同時執行多個任務？

    MaaNTE 透過影像辨識與模擬鍵鼠操作實現自動化，多個任務同時執行會互相干擾。因此 MaaNTE 設計為順序執行。

- 什麼是控制器？各控制器有什麼差別？

    控制器是 MaaFramework 中用於與遊戲視窗互動的元件。MaaNTE 提供三種控制器：

    - **桌面端-預設**：在遊戲視窗失焦時以後台方式操作，任務執行時仍可使用電腦做其他事情，偶爾會出現「搶滑鼠」的情況。
    - **桌面端-前台**：直接操作前台遊戲視窗。任務執行時遊戲視窗必須保持可見且不可被遮擋，會完全占用滑鼠，期間無法使用電腦做其他事情。
    - **桌面端-後台**：在後台模擬操作，遊戲視窗可以被遮擋但不可最小化，透過讓視窗移動來避免滑鼠亂飛。

    你可以在右上角連線設定中選擇合適的控制器。每個任務文檔也會標註支援的控制器類型。

- 為什麼有些任務需要特定控制器？

    部分任務中的操作在某些控制器下會有問題，因此做了限制。具體支援哪些控制器，請參考對應任務文檔中的控制器說明。

    一般而言，控制器限制與控制器特性以及《異環》的一些奇妙問題有關。

- 如何知道任務是否正常執行？

    任務執行過程中，可以在 MaaNTE 的日誌面板查看即時日誌。若任務異常或失敗，日誌中會有對應錯誤提示。

    如果任務無法正常執行，請參考[問題排查手冊](trouble_shooting.md)排查。

## MaaNTE 功能

::: collapse

- MaaNTE 有哪些主要功能？

    MaaNTE 目前涵蓋《異環》中部分可自動化玩法，可前往[功能介紹](../introduction/README.md)查看完整功能列表與詳細說明。

- 各功能出問題時該怎麼辦？

    請先參考[功能介紹](../introduction/README.md)與[問題排查手冊](trouble_shooting.md)嘗試解決。如果問題仍存在，可以聯絡我們回報。

- 資料收集功能是什麼？

    資料收集功能用於採集開發與最佳化 MaaNTE 功能所需的資料（如自動駕駛資料集訓練資料）。這些功能**預設不會開啟**，且採集的資料**不會自動上傳到網路**，需要你手動傳送給開發者。

- MaaNTE 支援哪些遊戲功能？未來會有哪些功能？

    MaaNTE 功能仍在持續開發。目前仍有部分玩法尚未支援，你可以關注 [GitHub Releases](https://github.com/1bananachicken/MaaNTE/releases) 了解最新版本功能更新。

    如果你希望支援某個功能，可以透過 GitHub Issues 或官方 QQ 群向開發者回饋。

:::

## MaaNTE 線上地圖工具

::: collapse

- 什麼是 MaaNTE 線上地圖工具？

    [MaaNTE 線上地圖工具](https://map.maante.org/) 是《異環》的網頁地圖工具。相較其他地圖，它提供即時定位與路線分享功能。

- 如何使用即時定位功能？

    即時定位功能需要配合其他支援工具使用（例如 MaaNTE）。我們公開了該功能的介面，歡迎任何工具接入。

    關於如何配合 MaaNTE 使用此功能，請參考相關文檔。
:::
