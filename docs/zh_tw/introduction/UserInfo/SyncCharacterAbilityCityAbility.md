---
title: 記錄角色都市特技
---

## 簡介

辨識全部角色的都市特技等級並記錄到設定檔。

::: warning

執行本任務前，務必先在 MaaNTE 的設定中設好 `結束任務快捷鍵` 並開啟 `全域快捷鍵`。

:::

::: info 控制器

- [ ] 桌面端-預設
- [x] 桌面端-前台
- [ ] 桌面端-後台

:::

::: steps

1. 全新記錄

    開啟後會覆蓋既有的角色都市特技記錄。

    ::: warning

    會清空之前的全部記錄。

    :::
    ::: tip

    發現先前的記錄有問題時，可以使用此選項清空並覆蓋原有內容。

    :::
:::

::: info

此功能與一些其他未完成的功能有關。

:::
