---
title: キャラクターシティアビリティを記録
---

## 概要

全キャラクターのシティアビリティレベルを認識し、設定ファイルに記録します。

::: warning

このタスクを実行する前に、MaaNTE の設定で `タスク終了ホットキー` を設定し、`グローバルホットキー` を有効にしてください。

:::

::: info コントローラー

- [ ] デスクトップ - デフォルト
- [x] デスクトップ - フォアグラウンド
- [ ] デスクトップ - バックグラウンド

:::

::: steps

1. 新規記録

    有効にすると、既存のキャラクターシティアビリティ記録を上書きします。

    ::: warning

    以前の記録はすべて消去されます。

    :::
    ::: tip

    以前の記録に問題がある場合、このオプションで既存内容を消去して上書きできます。

    :::
:::

::: info

この機能は、まだ完成していないほかの機能と関連しています。

:::
