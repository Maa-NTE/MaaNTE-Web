## MXU（画面）

::: collapse

- MXU とは何ですか？

    [MXU](https://github.com/MistEO/MXU)（MaaFramework Next UI）は、[MaaFramework PI V2](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.3-ProjectInterfaceV2%E5%8D%8F%E8%AE%AE.md) プロトコルに基づく汎用 GUI クライアントです。本プロジェクトにすぐ使えるグラフィカル画面を提供します。

- なぜ MXU を選んだのですか？

    本プロジェクト初期は [MFAAvalonia](https://github.com/MaaXYZ/MFAAvalonia) を使用していました。これは [MaaFramework プロジェクトテンプレート](https://github.com/MaaXYZ/MaaPracticeBoilerplate) に含まれる GUI です。しかし、設定方法、操作感、導入しやすさが本プロジェクトの要求に完全には合いませんでした。[M9A](https://github.com/MAA1999/M9A)、[MAAEnd](https://github.com/MaaEnd/MaaEnd) などを参考にしたうえで、開発者内で検討し MXU に切り替えました。

    MaaNTE にとって、MXU は設定が簡単で、画面操作がしやすく、ログ管理も優秀で、.NET ランタイムも不要です。まだ不足点はありますが、現在の主流 MaaFramework GUI の中では最も適しています。別の GUI を使いたい場合は、自分で管理することもできます。
:::

### 設定／タブ

::: collapse

- 設定／タブとは何ですか？

    MXU は MaaFramework の設定をタブ形式で表示します。用途に応じて設定を切り替えるための仕組みです。

- 設定ごとに何が分かれていますか？

    MXU では「各設定のタスクとデバイス設定は互いに独立」と説明されています。

    実際には、タスクリスト、詳細オプション、有効状態、展開状態、スケジュール、接続設定、コントローラー、接続ウィンドウ、リアルタイムスクリーンショット表示状態などが設定ごとに独立しています。設定ページ内の内容は各設定で共有されます。

- プリセット設定について

    よく使う設定をいくつかプリセットとしてまとめており、初回起動時に自動で適用されます。不要な場合はタブを閉じて削除できます。

    誤ってプリセットを削除した場合は、新しい設定を作成するときに対応するプリセットを選べば再追加できます。

- スケジュール実行について

    設定の右下にあるスケジュール機能で、その設定を指定時刻に実行できます。この機能は設定ごとに独立しています。
:::

### タスク

::: collapse

- タスクとは何ですか？

    MaaNTE の各自動化機能は独立した「タスク」として扱われ、必要に応じて有効化または無効化できます。各タスクは、[報酬受け取り](../introduction/Daily/ClaimRewards.md) や [釣りタスク](../introduction/HethereauHobbies/Fish.md) など、ゲーム内の具体的な操作や遊び方に対応します。

    実行したいタスクをタスクリストで選択すると、MaaNTE はリスト順に実行します。

- タスクはどのように分類されていますか？

    タスクは主に機能タイプごとに分類されています。

    - **日常タスク**：活躍度報酬、環期賞令報酬、家具報酬、一珈舎収益など、毎日繰り返す操作。
    - **リアルタイム支援**：自動拾得、ストーリースキップ、自動転送、音声回避、クイックピックアップなど、プレイ中に動作する補助機能。
    - **シティ名声**：一珈舎経営、不動産家具などの関連機能。
    - **シティライフ**：コーヒー作成、釣り、ピンクポー大強奪、テトリミノ、超強音などのミニゲーム自動化。
    - **その他機能**：自動ピアノ、撫でる、噴水チェックインなどの娯楽機能や未完成機能。
    - **データセットコレクション**：機能開発と改善に必要なデータ収集。デフォルトでは有効になりません。

    各タスクの詳細は[機能紹介](../introduction/README.md)を参照してください。

- タスクリストとは何ですか？

    タスクリストは MXU タブの左側にある大きな領域で、その設定に追加されたタスクを表示します。ここで各タスクの詳細設定を行えます。

- タスクの実行順序はどうなりますか？

    タスクは**タスクリストの上から下へ順番に実行**されます。チェックされていないタスクはスキップされます。タスクタイトル左側の六つの点をドラッグすると順序を変更できます。

- なぜ複数タスクを同時に実行できないのですか？

    MaaNTE は画像認識とマウス・キーボード入力のシミュレーションで自動化します。複数タスクを同時に実行すると操作が干渉するため、順番に実行する設計になっています。

- コントローラーとは何ですか？違いは何ですか？

    コントローラーは、MaaFramework がゲームウィンドウとやり取りするためのコンポーネントです。MaaNTE には 3 種類のコントローラーがあります。

    - **デスクトップ - デフォルト**：ゲームウィンドウがフォーカスされていないときもバックグラウンド方式で操作します。通常はタスク実行中も PC を使えますが、まれにマウス操作を奪うことがあります。
    - **デスクトップ - フォアグラウンド**：前面のゲームウィンドウを直接操作します。実行中はゲームウィンドウを表示したまま遮らない必要があり、マウスは完全に占有されます。
    - **デスクトップ - バックグラウンド**：バックグラウンドで操作をシミュレートします。ウィンドウは隠れていてもよいですが、最小化はできません。マウスの代わりにウィンドウを動かして操作を安定させます。

    右上の接続設定で適切なコントローラーを選択できます。各タスク文書にも対応コントローラーが記載されています。

- なぜ一部のタスクは特定のコントローラーが必要なのですか？

    一部の操作は特定のコントローラーで問題が出るため制限されています。各タスクが対応するコントローラーは、そのタスクの文書を確認してください。

    多くの場合、制限はコントローラーの特性やゲーム側の挙動に関係しています。

- タスクが正常に動いているか確認するには？

    タスク実行中は MaaNTE のログパネルでリアルタイムログを確認できます。異常や失敗がある場合、ログに対応するエラーが表示されます。

    正常に動作しない場合は[トラブルシューティング](trouble_shooting.md)を参照してください。
:::

## MaaNTE の機能

::: collapse

- MaaNTE の主な機能は何ですか？

    MaaNTE は『Neverness to Everness』内で自動化できる一部の遊び方をカバーしています。完全な機能一覧と詳細は[機能紹介](../introduction/README.md)を参照してください。

- 各機能に問題がある場合はどうすればよいですか？

    まず[機能紹介](../introduction/README.md)と[トラブルシューティング](trouble_shooting.md)を確認してください。それでも解決しない場合は、連絡して報告してください。

- データ収集機能とは何ですか？

    データ収集機能は、MaaNTE の機能開発と改善に必要なデータ（自動運転データセットの訓練データなど）を収集するためのものです。これらの機能は**デフォルトでは有効にならず**、収集データも**自動でネットワークへアップロードされません**。開発者へ送る場合は手動で送信する必要があります。

- MaaNTE はどの機能をサポートしていますか？今後は？

    MaaNTE は継続的に開発されています。まだ対応していない遊び方もあります。最新機能は [GitHub Releases](https://github.com/1bananachicken/MaaNTE/releases) を確認してください。

    対応してほしい機能がある場合は、GitHub Issues または公式 QQ グループでフィードバックしてください。
:::

## MaaNTE オンラインマップツール

::: collapse

- MaaNTE オンラインマップツールとは何ですか？

    [MaaNTE オンラインマップツール](https://map.maante.org/) は『Neverness to Everness』向けの Web マップです。他のマップと比べ、リアルタイム位置表示とルート共有に対応しています。

- リアルタイム位置表示はどう使いますか？

    リアルタイム位置表示は、MaaNTE など対応ツールと組み合わせて使用します。この機能のインターフェースは公開されており、他のツールからの連携も歓迎しています。

    MaaNTE と組み合わせて使う方法は、関連文書を参照してください。
:::
