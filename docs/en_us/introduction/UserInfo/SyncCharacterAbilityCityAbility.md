---
title: Record Character City Abilities
---

## Overview

Recognizes all characters' city ability levels and records them in the configuration file.

::: warning

Before running this task, make sure the `stop task hotkey` is configured in MaaNTE settings and that `global hotkeys` are enabled.

:::

::: info Controller

- [ ] Desktop - Default
- [x] Desktop - Front
- [ ] Desktop - Background

:::

::: steps

1. Fresh record

    When enabled, this overwrites existing character city ability records.

    ::: warning

    All previous records will be cleared.

    :::
    ::: tip

    Use this option when earlier records are incorrect and need to be cleared and replaced.

    :::
:::

::: info

This feature is related to some other unfinished features.

:::
