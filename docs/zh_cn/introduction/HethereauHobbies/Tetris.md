## 简介

自动玩俄罗斯方块。需要在该玩法界面开始任务。

::: info 控制器

- [x] 桌面端-默认
- [x] 桌面端-前台
- [x] 桌面端-后台

:::

::: steps

1. 自动连打

    启用后自动重复多轮，关闭则仅进行一轮

2. 消耗所有活力

    启用后连续游玩直到没有足够都市活力用于领取方斯奖励。关闭后可设置`连打轮数`。

3. 连打轮数

    连续游玩多少次。

4. 允许速降

    启用后方块平移/旋转结束后自动按空格键快速下落。
:::
