---
title: 记录角色都市特技
---

## 简介

识别全部角色的都市特技等级并记录于配置文件。

::: warning

执行本任务前，务必在 MaaNTE 的设置中设置好`结束任务快捷键`并开启`全局快捷键`。

:::

::: info 控制器

- [ ] 桌面端-默认
- [x] 桌面端-前台
- [ ] 桌面端-后台

:::

::: steps

1. 全新记录

    开启后会覆盖已有的角色都市特技记录。

    ::: warning

    会清空之前的全部记录。

    :::
    ::: tip

    发现之前的记录有问题时可以使用该选项清空并覆盖之前的内容。

    :::
:::

::: info

该功能与一些其它未完成的功能有关。

:::
