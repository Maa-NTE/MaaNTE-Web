## MXU（界面）

::: collapse

- 什么是 MXU ？

    [MXU](https://github.com/MistEO/MXU)（MaaFramework Next UI），是一个基于 [MaaFramework PI V2](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.3-ProjectInterfaceV2%E5%8D%8F%E8%AE%AE.md) 协议的通用 GUI 客户端。它为本项目提供了开箱即用的图形界面。

- 为什么选择 MXU ？

    本项目早期采用的是[MFAAvalonia](https://github.com/MaaXYZ/MFAAvalonia)，这也是 [MaaFramework 项目模板](https://github.com/MaaXYZ/MaaPracticeBoilerplate)内置的 GUI 。但是在使用过程中我们发现其配置方式、交互逻辑、上手难度等对我们的需求而言并不合适，在参考了 [M9A](https://github.com/MAA1999/M9A)、[MAAEnd](https://github.com/MaaEnd/MaaEnd)等项目后，经开发者内部讨论决定改用 MXU 。

    对我们来说，MXU 有配置简单、界面交互方便、日志管理优秀、无需.NET运行库等优点。虽然仍有些许不足之处，但是是主流 MaaFramework GUI 中最为合适的。当然，如果你更喜欢其它 GUI ，也可以自行管理
:::

### 配置/标签页

::: collapse

- 什么是配置/标签页？

    MXU 将 MaaFramework 配置以标签页的形式展示，以便用户选择合适的配置用于不同用途。

- 配置包括的范围有哪些？

    MXU 描述为`各配置的任务和设备设置互相独立。`

    实际上，配置间的任务（任务列表、任务详细配置、任务启用状态、任务展开状态等）独立；定时功能独立；连接设置（控制器、连接窗口、实时截图显示状态等）独立。设置中的内容各配置共享。

- 关于预制配置

    我们将部分常用配置整合为了几份预设，在首次启动软件时会自动应用。当然，如果不需要的话也可以通过关闭标签页的方式来删除该配置。

    如果你误删了预设配置，想要将其重新添加回来，只需要在新建配置时选择对应预设即可。

- 关于定时执行配置

    在配置的右下角，可以通过定时功能让某个配置定时执行。该功能各配置相互独立。
:::

### 任务

::: collapse

- 什么是任务？

    MaaNTE 中各个自动化功能作为独立的"任务"，你可以根据需要自由启用或禁用。每个任务对应游戏中的一个具体操作或玩法，例如[领取奖励](../introduction/Daily/ClaimRewards.md)、[自动钓鱼](../introduction/HethereauHobbies/Fish.md)等。

    你可以在任务列表中勾选需要执行的任务，MaaNTE 会按列表顺序依次执行。

- 任务是如何分类的？

    任务主要按其功能类型分为以下几类：

    - **日常任务**：领取活跃度奖励、环期赏令奖励、家具奖励、一咖舍收益等每日重复性操作。
    - **实时辅助**：自动拾取、跳过剧情、自动传送、音频闪避、快速拾取等在进行游戏时运行的辅助功能。
    - **都市大亨**：一咖舍经营、房产家具等都市大亨玩法下的相关功能。
    - **都市闲趣**：自动做咖啡、钓鱼、粉爪大劫案、俄罗斯方块、超强音等都市闲趣中的小游戏自动化。
    - **其它功能**：自动弹琴、抚摸、喷泉打卡等娱乐性功能与暂时还不完善的功能。
    - **数据收集**：用于开发和优化功能的数据采集，默认不开启。

    你可以前往[功能介绍](../introduction/README.md)查看各类任务的详细说明。

- 什么是任务列表？

    任务列表是 MXU 标签页下位于偏左位置的一大片区域，用于展示该配置中添加了的各个任务。你可以在此处对各任务进行详细的设置。

- 任务的执行顺序是怎样的？

    任务是**按任务列表从上到下依次执行**的，会跳过未勾选的任务。你可以通过拖拽任务标题左侧的六个点来调整顺序。

- 为什么不支持同时执行多个任务？

    MaaNTE 通过图像识别与模拟键鼠操作来实现自动化，多个任务同时执行会导致操作互相干扰。因此 MaaNTE 设计为顺序执行。

- 什么是控制器？各控制器有什么区别？

    控制器是 MaaFramework 中用于与游戏窗口交互的组件。MaaNTE 提供了三种控制器：

    - **桌面端-默认**：在游戏窗口失焦时通过后台方式进行操作，任务运行时你仍可使用电脑做其他事情。偶尔会出现“抢鼠标”的现象。
    - **桌面端-前台**：直接操作前台游戏窗口。任务运行时游戏窗口必须保持可见且不被遮挡，会完全强占鼠标，期间你无法使用电脑做其他事情。
    - **桌面端-后台**：在后台模拟操作，游戏窗口可以被遮挡但不可最小化。通过让窗口飞来飞去来保证鼠标不会飞来飞去。

    你可以在右上角的连接设置中选择合适的控制器。每个任务文档中也都标注了其支持的控制器类型。

- 为什么有些任务需要特定控制器？

    部分任务中的操作在使用某些控制器时会存在问题，所以进行了限制。具体每个任务支持哪些控制器，请参阅对应任务文档中的控制器说明。

    一般来说，限制控制器与控制器的特性及异环的奇妙bug有关。

- 如何知道任务是否正常运行？

    任务执行过程中，你可以在 MaaNTE 的日志面板中查看实时运行日志。如果任务出现异常或失败，日志中会有相应的错误提示。

    如果遇到任务无法正常运行的情况，请参考[问题排查手册](trouble_shooting.md)进行排查。

:::

## MaaNTE 功能

::: collapse

- MaaNTE 有哪些主要功能？

    MaaNTE 目前涵盖了《异环》中部分可自动化的玩法，你可以前往[功能介绍](../introduction/README.md)查看完整功能列表及各功能的详细说明。

- 各个功能有问题时应该怎么办？

    请先参考[功能介绍](../introduction/README.md)和[问题排查手册](trouble_shooting.md)尝试解决问题。如果还存在问题，可以联系我们反馈。

- 数据收集功能是什么？

    数据收集功能用于采集开发和优化 MaaNTE 功能所需的数据（如自动驾驶数据集的训练数据）。这些功能**默认不会开启**，且采集的数据**不会自动上传到网络**，需要你手动将数据发送给开发者。

- MaaNTE 支持哪些游戏功能/未来会有哪些功能？

    MaaNTE 的功能正在持续开发中。目前仍有一些玩法尚未支持（如部分都市闲趣玩法），你可以关注 [GitHub Releases](https://github.com/1bananachicken/MaaNTE/releases) 了解最新版本的功能更新。

    如果你有希望支持的功能，可以通过 GitHub Issues 或官方 QQ 群向开发者反馈。

:::

## MaaNTE 在线地图工具

::: collapse

- 什么是 MaaNTE 在线地图工具？

    [MaaNTE 在线地图工具](https://map.maante.org/)，是一个异环的网页地图工具。相比于其它地图，有着实时定位、路线共享的功能。

- 如何使用实时定位功能？

    实时定位功能需要配合其它支持的工具使用（例如 MaaNTE）。我们公开该功能的接口，欢迎任何工具接入。

    关于如何配合 MaaNTE 使用该功能，请参考文档。
:::
